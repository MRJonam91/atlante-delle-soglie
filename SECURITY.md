# Sicurezza / Security

IT: Questa versione contiene documenti, SVG statiche e strumenti di controllo; non include un server di gioco. Per problemi ordinari aprire un'issue. Per segreti esposti o vulnerabilità, usare **Security → Report a vulnerability** se disponibile, oppure un contatto pubblico del profilo del manutentore. Non incollare credenziali, salvataggi o dati dei giocatori in pubblico. Non è promesso un tempo di risposta o un programma di ricompense.

EN: This version contains documents, static SVGs and check tools, not a game server. Use issues for ordinary problems. For exposed secrets or vulnerabilities, use **Security → Report a vulnerability** if available, or the maintainer profile's public contact. Never paste credentials, saves or player details publicly. No response-time or bounty commitment is made.
